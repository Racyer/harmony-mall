# 测试与验收

| 项目 | 要求 |
| --- | --- |

| 工具 | DevEco Studio 5.0.5+ |
| SDK | API 12（与工程 `compatibleSdkVersion` 一致） |

## 3. 兼容与性能

- **尺寸**：360×780、390×844、平板 1280×800 各走一遍首页与购物车。
- **深色模式**：当前固定浅色；开启深色模式后不应出现白底白字。
- **性能**：首页 16 件商品首屏加载不超过 2 秒；快速滑动不卡顿。
- **内存**：反复进入详情/返回 20 次，无持续增长或崩溃。

## 4. 缺陷分级

| 级别 | 定义 | 处理时限 |
| --- | --- | --- |
| P0 | 崩溃、白屏、主流程阻断 | 当天修复 |
| P1 | 金额错误、登录失效、订单丢失 | 24 小时内 |
| P2 | 样式错位、提示文案错误 | 本周内 |
| P3 | 体验优化、非关键动效 | 有余力再做 |

缺陷统一提 Issue，附复现步骤、截图/录屏、设备与版本。

# 提交清单

## 1. 提交物

| 内容 | 形式 | 负责人 | 说明 |
| --- | --- | --- | --- |
| 源程序 | 文件夹 / 压缩包 | A | 不含 `build/`、`oh_modules/`、`.hvigor/`、签名文件 |
| 演示视频 | MP4，3–5 分钟 | D | 1080p，含解说，按主流程录制 |
| 分工文档 | DOCX | A | `docs/四人分工方案.docx` |
| 设计与说明 | Markdown / DOCX | A/B | 需求、概要设计、接口、测试 |
| 运行截图 | PNG（可选） | D | 首页、详情、购物车、订单各 1 张 |

## 2. 压缩包命名

格式：

```text
《移动应用开发》大作业_鸿蒙优选_组长姓名_成员姓名1_成员姓名2_成员姓名3.zip
```

示例（把占位替换为真实姓名）：

```text
《移动应用开发》大作业_鸿蒙优选_张三_李四_王五_赵六.zip
```

要求：

- 文件名必须包含 **全部四位成员姓名**，顺序为组长在前。
- 压缩包内再放一层同名文件夹，避免解压后文件散落。
- 若课程平台限制文件名长度，可简写为 `移动应用开发大作业_鸿蒙优选_张三_李四_王五_赵六.zip`，但姓名不能省略。

## 4. 演示视频脚本

| 时间 | 画面 | 解说要点 |
| --- | --- | --- |
| 0:00–0:20 | 应用图标、启动、首页 | 项目名称、团队、技术栈 |
| 0:20–1:10 | 首页上下滑动、下拉刷新、上拉加载 | 商品列表、LazyForEach、到底提示 |
| 1:10–1:40 | 六个品类切换、分类页 | 多品类与分类联动 |
| 1:40–2:10 | 搜索“耳机”、进入详情、收藏 | 搜索命中、详情信息、收藏 |
| 2:10–2:50 | 加入购物车、修改数量、全选、合计 | 购物车交互与金额计算 |
| 2:50–3:30 | 未登录结算 → 登录 → 提交订单 → 订单列表 | 登录拦截与下单闭环 |
| 3:30–3:50 | 个人中心、地址、收藏 | 用户模块与持久化 |
| 3:50–4:00 | 结尾 | 分工总结、仓库地址 |

录制要求：横屏或竖屏统一；关闭通知；语速平稳；关键操作可加字幕。

# 接口与数据模型

## 1. 数据模型

### 1.1 商品与分类

```ts
export interface Category {
  id: number;
  name: string;
  icon: string;
  desc: string;
}

export interface Product {
  id: number;
  name: string;
  subtitle: string;
  price: number;
  originalPrice: number;
  image: ResourceStr;
  categoryId: number;
  tags: string[];
  sales: number;
  rating: number;
  description: string;
}
```

### 1.2 购物车

```ts
export interface CartItem {
  productId: number;
  quantity: number;
  selected: boolean;
}

export interface CartLine {
  product: Product;
  quantity: number;
  selected: boolean;
}
```

> 购物车持久化只存 `productId` 与数量，商品信息由 `ProductService` 实时补齐，避免把 `Resource` 写入 JSON。

### 1.3 订单

```ts
export interface OrderItem {
  productId: number;
  name: string;
  price: number;
  quantity: number;
}

export interface Order {
  id: string;
  items: OrderItem[];
  total: number;
  status: string;
  createdAt: string;
  address: string;
}
```

订单保存商品快照，商品下架后历史订单仍可展示。

## 2. 服务接口

| 服务 | 方法 | 说明 |
| --- | --- | --- |
| `ProductService` | `getAll()` | 全部商品 |
| `ProductService` | `getById(id)` | 按 id 查询，未找到返回 `undefined` |
| `ProductService` | `getByCategory(categoryId, offset, limit)` | 分页查询，`0` 表示精选（全部） |
| `ProductService` | `search(keyword)` | 名称、副标题、标签模糊匹配 |
| `ProductService` | `getTotalCount(categoryId)` | 品类商品数 |
| `CartService` | `add / remove / updateQuantity / toggleSelected / toggleAll` | 购物车写操作 |
| `CartService` | `getLines / getSelectedLines / getSelectedTotal` | 购物车读操作 |
| `CartService` | `removeSelected / clear` | 下单后清理 |
| `FavoriteService` | `toggle(id) / isFavorite(id) / getProducts()` | 收藏 |
| `AuthService` | `login(account, password) / logout()` | Mock 登录 |
| `OrderService` | `create(lines, address) / getOrders()` | 订单创建与查询 |

## 3. 路由参数

```ts
export class ProductParams {
  id: number = 0;
  constructor(id: number) { this.id = id; }
}

export class SearchParams {
  keyword: string = '';
  constructor(keyword: string) { this.keyword = keyword; }
}
```

使用 class 而不是对象字面量，满足 ArkTS 对显式类型的约束。

## 5. 后续接入真实后端

保持 `service` 方法签名不变，把内部实现替换为 `@ohos.net.http` 请求即可。建议接口映射：

| 前端方法 | 建议 REST |
| --- | --- |
| `getByCategory` | `GET /api/products?categoryId=&page=&size=` |
| `getById` | `GET /api/products/{id}` |
| `search` | `GET /api/products/search?keyword=` |
| `login` | `POST /api/auth/login` |
| `create order` | `POST /api/orders` |
| `getOrders` | `GET /api/orders` |

接入后需要补充：请求超时、错误码、Loading、空状态、Token 刷新。

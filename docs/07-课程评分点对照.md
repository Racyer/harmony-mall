# 课程评分点对照

课程任务书对“商城”方向的评分点为：设计分析 20 分、绘制页面 25 分、页面操作 35 分、多品类 20 分。本项目在完成基础要求的同时扩展了购物与登录，以下为评分点与代码/文档的对应关系。

## 1. 设计分析（20 分）

| 评分要求 | 对应材料 |
| --- | --- |
| 项目背景、目的 | `docs/01-需求分析.md` 第 1–2 节 |
| 功能划分 | `docs/01-需求分析.md` 第 3 节功能表 |
| 流程图 | `docs/01-需求分析.md` 第 5 节 Mermaid 流程图 |
| 架构与模块设计 | `docs/02-概要设计.md` |
| 数据模型与接口 | `docs/03-接口与数据模型.md` |

## 2. 绘制页面（25 分）

| 评分要求 | 对应实现 |
| --- | --- |
| 商品列表页面 | `entry/src/main/ets/components/ProductFeed.ets`、`ProductCard.ets` |
| 首页布局 | `views/home/HomeView.ets`（头部、搜索、轮播、快捷入口、Tab） |
| 分类页 | `views/category/CategoryView.ets` |
| 购物车 | `views/cart/CartView.ets` |
| 个人中心 | `views/profile/ProfileView.ets` |
| 二级页面 | `pages/ProductDetailPage.ets`、`SearchPage.ets`、`LoginPage.ets`、订单与地址页 |

## 3. 页面操作（35 分）

| 评分要求 | 对应实现 |
| --- | --- |
| 支持上下滑动 | `ProductFeed` 使用 `List` + `LazyForEach`，`edgeEffect(Spring)` |
| 下拉刷新 | `Refresh({ refreshing: $$this.isRefreshing })` + `onRefreshing` |
| 到底提示 | `List.onReachEnd` + `Footer()` 三种状态（加载中/上拉加载/已经到底了） |
| 交互闭环 | 搜索、详情、加购、购物车、结算、订单、登录 |

## 4. 多品类（20 分）

| 评分要求 | 对应实现 |
| --- | --- |
| 精选、手机、电脑、穿戴、家居、配件 | `HomeView.ProductTabs()` 六个 `TabContent` |
| 分类数据 | `data/MockData.ets` 的 `CATEGORIES` 与 16 件商品 |
| 分类页联动 | `CategoryView` 左侧品类 + 右侧商品列表 |

## 5. 演示建议

1. 先展示首页滑动、下拉刷新、上拉加载（对应 35 分核心）。
2. 再切换六个品类、进入分类页（对应 20 分）。
3. 展示搜索、详情、收藏（页面与交互加分）。
4. 最后走“加购 → 登录 → 下单 → 订单”闭环（体现完整商城能力）。
5. 结尾展示 GitHub 仓库与分工文档（体现团队协作）。
